## Хронология
- Старт: пул на Railway, агенты через `agy` (Gemini CLI с личным OAuth не поддерживается).
- Панель: агенты, задачи, ошибки, проверка лимита, модель на агента, живые таймеры.
- Коннектор Claude с OAuth 2.1, режим обслуживания и безопасный деплой, авто-ревью через Monitor и `pool_watch.py`.
- Том Railway переполнился (sqlite disk I/O error): добавлена уборка и защита диска; расширить том на тарифе нельзя, переезд на VPS Aéza (Ubuntu, Caddy, systemd, ufw, fail2ban, swap). Проект на Railway удалён.
- Онбординг аккаунтов: `add_account.sh` и форма на панели.
- Раздельные исходящие IPv6 на агента (прокси `app/egress_proxy.py`).
- Конвейеры с ревью, стадии на панели, подсказки по моделям, отмена задач в очереди, пауза агента до времени сброса лимита от Google.
- Аккаунты: acc1, acc2 и acc3 по очереди теряли вход или требовали верификацию; добавлены acc3 (ревьюер) и acc4.

- 2026-10-21: загрузки файлов (`app/uploads.py`): раздел «Хранилище» на панели (постоянные и обычные отдельно, список файлов, удаление файла/загрузки), общий лимит 10 ГБ, постоянные файлы (pinned); решение владельца: НЕТ «правил для всех задач» (путаница между проектами), правила проекта это постоянный файл, который Claude прикладывает к задачам через `submit_task uploads=[...]`, проект как репозиторий `repo="upload:<id>"`, MCP `list_uploads`. Выкачено на сервер 2026-10-21 (155 тестов), не закоммичено. Живая проверка: агент acc4 (flash-low) правильно описал загруженный скриншот, включая русский текст. Видео ещё не проверено (на Mac нет ffmpeg для тестового ролика): проверить на первом реальном видео.

## Решения и причины
- Только stdlib Python: простой деплой на голый VPS без зависимостей.
- Гонка при одновременном старте двух worktree (`.git/config` lock): блокировка на репозиторий и `--no-track`.
- Агент мог сам закоммитить: коммит пула пропускается, если нечего коммитить.
- Прогон тестов самого пула перебивает APPROVE ревьюера.
- Модельный каталог берётся с первого аккаунта (ограничение: диспетчер не учитывает, какие модели есть у какого аккаунта).
